# dct2201-banco-de-dados
Atividades e projetos da disciplina Banco de Dados

## Tarefa 03 — Docker, MariaDB e Administração de SGBD

Os arquivos desta atividade estão localizados na pasta `tarefa03/`.

### Arquivos da atividade

- `docker-compose.yml`: configuração dos serviços MariaDB e CloudBeaver.
- `.env.example`: exemplo das variáveis de ambiente necessárias.
- `.gitignore`: lista de arquivos que não devem ser versionados.
- `setup.sql`: criação do banco de dados, tabelas e usuários.
- `povoamento.sql`: inserção dos autores e livros utilizados nos testes.
- `consultas.sql`: consultas SQL obrigatórias da atividade.

### Segurança

O arquivo `.env` contém configurações locais e senhas reais, portanto não deve ser enviado ao repositório. Utilize `.env.example` como referência para configurar o ambiente.
